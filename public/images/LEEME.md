# Imágenes del sitio

Coloca aquí las imágenes con estos nombres. Si alguna falta, el sitio muestra un placeholder automáticamente.

| Archivo | Uso |
|---|---|
| `/logo.png` (raíz de `public/`) | Logotipo oficial (header y footer). Fondo transparente, cuadrado. |
| `galeria/hero.jpg` | Imagen principal del inicio (≥1920 px de ancho). |
| `bienvenida.jpg` | Sección de bienvenida del inicio (vertical 4:5). |
| `galeria/historia.jpg`, `mision.jpg`, `vision.jpg`, `galeria/valores.jpg`, `galeria/liderazgo.jpg` | Quiénes somos. |
| `pastor-pedro.jpg`, `pastora-fatima.jpg` | Fotos de los pastores (cuadradas). |
| `ministerios/*.jpg` | jovenes, lideres, discipulado, esperanza, evangelismo, alabanza, intercesion, multimedia. |
| `galeria/1.jpg` … `galeria/9.jpg` | Galería. |

Recomendado: exportar en WebP/JPG comprimido. Cuando el panel administrativo esté listo, las imágenes vendrán de Supabase Storage.
